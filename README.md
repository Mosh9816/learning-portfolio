## 📦 学習成果物一覧（Learning Portfolio）  

- [python-aggregation-tool](./python-aggregation-tool)   
  Python と pandas を使用して作成した売上データの自動集計ツール。

  Laravel を使用して作成した経費管理アプリケーション。

  やよいの白色申告オンラインを使用して、1ヶ月分の会計処理
