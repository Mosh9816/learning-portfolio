# やよい会計ポートフォリオ（Yayoi Accounting Portfolio）

このプロジェクトでは、**やよいの白色申告オンライン**を使用して  
**2026年4月の1ヶ月分の会計処理（売上・経費・家事按分・固定資産・減価償却）** を再現しました。

実務で必要となる基本的な会計フローを理解し、  
会計ソフトを使って処理できるスキルを身につけることを目的としています。

---

## 🚀 実施した処理内容

### ■ 売上・経費の入力
- 売上 3件（Web制作・バナー制作・LP制作）
- 経費 3件（Adobe CC・カフェ作業・PCスタンド）
- 振込手数料（330円）

### ■ 家事按分
- 通信費：50%
- 水道光熱費：30%
- やよいの自動按分機能を使用

### ■ 固定資産の登録
- ノートPC（120,000円）
- 耐用年数：4年
- 減価償却費：22,500円（自動計算）

### ■ レポート・帳簿の確認
- 仕訳帳
- 損益レポート
- 日別レポート
- 固定資産台帳

## 💡 工夫したポイント

- **実務の会計フローを1ヶ月分まるごと再現**
  - 売上・経費・按分・固定資産・減価償却まで一連の流れを操作
  - 会計ソフトの自動仕訳の仕組みを理解

- **固定資産と減価償却の理解**
  - 10万円以上の備品は固定資産として登録
  - やよいの自動計算で減価償却費を算出

- **レポートの読み方を習得**
  - 損益レポートで利益構造を把握
  - 日別レポートで1ヶ月の動きを確認
  - 固定資産台帳で償却状況を確認
